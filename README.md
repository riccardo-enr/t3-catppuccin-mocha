# Catppuccin Mocha for T3 Code

A calmer Catppuccin Mocha theme for T3 Code, with softer highlights and clearer controls.

![Toolbar with a subtle selected control](docs/img/toolbar.png)

## Changes

- Softer borders and more distinct panel surfaces.
- Subtle mauve selections instead of bright purple fills.
- Brighter placeholders and muted icons.
- A deeper cranberry Stop button with a readable white icon.

The changes apply to the dark variant. The original light variant is preserved.

## Install

Download [catppuccin-mocha.json](https://github.com/riccardo-enr/t3-catppuccin-mocha/blob/main/catppuccin-mocha.json?raw=1) and place it at:

```text
~/.t3/userdata/themes/catppuccin-mocha.json
```

Back up an existing file at that path before replacing it.

1. Open **Settings -> Appearance** in T3 Code.
2. Select **Dark**.
3. Choose **Catppuccin Mocha**.

If the theme is already selected, switch to another theme and back to refresh it.
If it does not appear in the list, restart T3 Code and open Appearance again.
